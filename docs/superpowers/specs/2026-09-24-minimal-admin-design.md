# First Look 最小管理后台设计

## 目标

提供一个足够网站初期上线使用的 `/admin` 管理后台。后台沿用现有邮箱登录，不依赖 Cloudflare 环境变量，不建立第二套账号系统。

## 管理员规则

- 数据库中最早注册的账号自动成为所有者。
- 所有者可以在后台添加或移除其他管理员。
- 所有者身份不可移除。
- 管理员不能禁用自己，也不能移除自己的管理员身份。
- 被禁用用户的现有会话立即失效，之后无法继续登录。

## 页面范围

- 概览：用户、产品、公开产品、待处理举报数量。
- 产品管理：搜索产品，查看状态，隐藏或恢复产品。
- 用户管理：搜索用户，禁用或恢复用户，设置管理员。
- 举报处理：查看待处理举报并标记为已处理。举报入口后续在互动模块接入。

## 数据安全

- 隐藏产品时记录原可见状态，恢复时回到原状态。
- 初期后台不提供永久删除产品或用户。
- 所有管理操作写入审计记录，包括管理员、动作、目标和时间。
- 所有写操作校验同源请求和管理员身份。

## 验收标准

- 首个注册账号无需外部配置即可访问 `/admin`。
- 普通登录用户访问后台接口返回无权限。
- 管理员可以隐藏及恢复产品、禁用及恢复用户、增减管理员。
- 所有者、当前管理员自身受到防误操作保护。
- 页面包含加载、空状态和错误提示，并适配手机。
- 类型检查和生产构建通过。
