# 已发布产品不可修改与整项删除设计

## 核心原则

产品一旦正式发布，其名称、介绍、创作思路、标签、链接、照片和视频都成为不可修改的发布记录。管理单位是整个产品，不允许编辑或删除单个历史节点。

## 作者操作

已发布产品只提供以下操作：

- 下架：从公开展示中移除产品，保留全部数据和发布记录。
- 重新上架：恢复公开展示，不修改原始发布内容。
- 删除产品：永久删除该产品及其完整过程。

“我的产品”移除编辑按钮，不再提供编辑页面入口。现有编辑 API 也必须拒绝已发布产品的修改请求，避免绕过页面直接修改数据。

## 删除交互

- 点击“删除产品”后打开确认对话框。
- 对话框显示产品名称，并明确说明将永久删除产品、发布记录、喜欢记录、照片和视频。
- 对话框提供“取消”和具有危险样式的“永久删除”按钮。
- 删除期间禁用重复提交。
- 删除成功后，该产品立即从“我的产品”页面消失。
- 删除失败时保留产品并显示明确错误，不让页面进入半删除状态。

## 数据删除

删除请求必须验证当前登录用户确实是产品作者，并验证同源请求。

删除范围包括：

- 产品主记录；
- 当前媒体记录；
- 所有版本快照；
- 所有生命周期事件；
- 所有喜欢记录；
- 当前媒体和历史版本引用的 R2 对象。

数据库关联记录以一个批次删除。R2 对象去重后清理；不存在的对象不视为失败。媒体清理异常必须记录，但不能留下仍可访问的产品数据库记录。

## 生命线调整

- 单个发布时间和媒体节点只可查看，不能编辑或删除。
- 保留下架和重新上架状态节点。
- 顶部“产品仍在成长”改为“发布记录”，避免暗示作者可以继续改写内容。
- 现有历史版本继续展示，但不再允许产生新的内容版本。

## 验收标准

1. 已发布产品不再显示“编辑”按钮。
2. 直接访问旧编辑地址不能修改产品，并引导返回“我的产品”。
3. 下架与重新上架继续正常工作。
4. 删除必须经过二次确认，且警告内容明确。
5. 删除成功后，产品不再出现在公开页面或“我的产品”中。
6. 该产品的版本、事件、喜欢和媒体记录被一并删除。
7. 不能单独编辑或删除任何生命线节点。
