# 管理员手动发送邮件

在现有管理员后台增加发送邮件入口。管理员可以搜索用户姓名或邮箱、逐个勾选或全选当前列表，填写主题和纯文本正文，确认收件人数及主题后发送。每位用户单独收到一封邮件，无法看到其他人的邮箱。已禁用账号不能选中。

复用现有阿里云SMTP发信功能和Cloudflare SMTP_PASSWORD配置，发件地址为noreply@mail.firstlooklab.cn。正文附First Look签名和server@firstlooklab.cn联系地址。每次请求最多处理5位收件人，网页依次提交直到处理所有选中的用户。

接口校验管理员身份、请求来源、有效账号、主题与正文长度。每批使用随机批次ID，数据库记录批次、管理员、用户、邮件内容及提交结果。每位收件人在同一批次只发送一次，网页可以在网络中断后使用同一批次继续，已处理的用户不会再次发送。发送成功表示SMTP服务已接受邮件，不保证邮件已进收件箱。失败和发送结果未确认的记录不会自动重试。

验收：用户可以选择多位收件人；每封邮件只有一位收件人；未授权请求不能发信；重提交同一批次不会重复发信；成功、失败和待发送状态逐人显示；通过类型检查和生产构建，验证过程中不给实际用户发送邮件。
