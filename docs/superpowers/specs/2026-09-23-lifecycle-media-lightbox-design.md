# 产品生命线媒体浏览器设计

## 目标

在“我的产品”的版本详情中加入全屏媒体浏览能力，让创作者能够清楚查看某次发布时保存的照片和视频，同时不改变现有生命线结构。

## 交互

- 点击生命线的小封面仍然只负责展开或收起该版本详情。
- 版本详情中的每张照片和视频改为可点击缩略图。
- 点击缩略图后打开全屏浏览器，并从被点击的媒体开始。
- 浏览器支持上一项、下一项、键盘方向键、触屏滑动和关闭。
- 照片支持缩放；视频使用浏览器控件播放，打开时不自动播放。
- 关闭浏览器后返回原版本详情，不改变生命线的展开状态。

## 视觉

- 使用深色全屏背景，让历史媒体成为视觉主体。
- 控件保持克制，只保留关闭、前后切换、计数和图片缩放。
- 缩略图增加轻微悬停反馈和“查看大图/播放视频”的辅助说明。
- 浏览器样式不改变 First Look 的标志、口号或页面排版。

## 技术边界

- 使用 `yet-another-react-lightbox`，只加载核心、Zoom 与 Video 插件。
- 媒体继续通过现有登录鉴权接口读取，不复制文件或公开 R2 地址。
- 浏览器组件与生命线拆分，避免生命线文件继续膨胀。
- 暂不加入下载、分享、幻灯片、缩略图导航或版本对比。

## 错误与无障碍

- 媒体加载失败时保留缩略图位置，不影响文字历史查看。
- 所有缩略图使用原生按钮，可用键盘打开。
- 全屏浏览器负责焦点管理、Escape 关闭及方向键操作。
- 遵循减少动态效果的系统设置。

## 验收标准

1. 点击版本详情中的任一照片或视频可以打开全屏浏览。
2. 全屏浏览从被点击项目开始，并可前后切换同一版本的媒体。
3. 照片可以缩放，视频可以播放且不会自动播放。
4. 关闭后仍停留在原来展开的版本节点。
5. 手机与桌面均可使用，键盘操作正常。
6. 未展开版本以及没有媒体的版本不增加额外交互。
