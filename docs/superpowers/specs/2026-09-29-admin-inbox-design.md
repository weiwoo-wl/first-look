# 管理后台 server 收件箱

用户已确认：后台邮件管理中查看 server@firstlooklab.cn 的来信和正文，并直接回复；保留现有发送记录。验证码发信不变，不接 noreply 收件，不删除、移动或自动标记已读邮件。

实现采用 Cloudflare TLS socket 连接阿里邮箱 IMAP 993，用现有 SERVER_SMTP_PASSWORD。INBOX 以 EXAMINE 只读打开，BODY.PEEK 读取。每页最多20封，只读邮件头；打开单封时读取正文，原始邮件最大2MB。以 UIDVALIDITY 和 UID 标识邮件，避免邮箱重建后错读。连接30秒超时，响应和字面量都有长度限制。未授权请求不连接邮箱；响应 no-store，不记录原文或密码。

邮件正文用 postal-mime 解析，网页仅显示文本；HTML-only 邮件转成纯文本，不注入DOM，附件仅列名称并提示到阿里邮箱查看。回复目标来自已读取邮件的 Reply-To / From，不接受客户端任意地址。回复需确认，使用独立幂等标识、记录发送状态，失败或不确定不自动重发；状态与旧发送记录一起显示。保留 In-Reply-To 和 References 供邮件客户端归并对话。

实现顺序：1 IMAP 只读适配和解析；2 管理员收件 API；3 幂等回复 API；4 后台收件组件及邮件导航；5 模拟协议分片、认证权限、HTML安全、回复去重测试；6 构建和推送。无真实邮件的测试不宣称线上收发已验证。
