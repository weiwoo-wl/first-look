# First Look 邮箱注册与登录

## 已确认的产品目标
访客可浏览；只有已注册、已登录的本站用户才能发布。邮箱验证码替代 GitHub 授权，无密码。相比邮箱密码少记忆负担，相比魔法链接不用切换页面完成登录，因此采用验证码。

## 用户流程
统一入口显示邮箱、获取验证码、验证码输入。首次使用须主动勾选用户协议与隐私政策，并点击“注册并登录”，才创建本站用户；已有账号点击“登录”。不预勾选协议，不仅凭发送验证码创建用户。成功返回发布页或首页的站内路径，保留发布草稿。失败显示明确错误，禁止重复提交。

## 服务与数据
使用 Cloudflare D1 新建 users、email_challenges、user_sessions 表，不删除现有作品及旧 sessions 表。users 使用独立随机用户 ID、唯一规范化邮箱、显示名、注册时间、协议版本及同意时间。挑战保存随机 ID、邮箱、用途、验证码带随机盐的哈希、到期时间、尝试次数、是否已消费。邮箱去除首尾空白并转为小写，不更改点号或加号。

验证码使用密码学随机源生成六位数字，有效期十分钟；同邮箱六十秒内不能重发，每小时最多五次。同 IP 每小时最多二十次，全站每日最多一千次发送尝试，保护短信替代方案的邮件费用；发送前用数据库原子操作预留额度。验证最多五次，旧验证码在重发后失效；成功消费须原子检查，不允许重放或并发重复注册。注册重复邮箱不产生多个用户。

发信使用 cloudflare:sockets 连接 smtpdm.aliyun.com:465，开启 TLS，认证账号 noreply@mail.firstlooklab.cn，密码只读取运行时 SMTP_PASSWORD。邮件发送模块与认证接口隔离，设置连接/响应超时、解析 SMTP 多行响应和失败状态、关闭连接；不记录密码、验证码、完整邮件或认证报文。配置缺失及发信失败不显示成功，也不能绕过邮箱验证。使用实际发信确认可达性，不用测试验证码冒充完成。

## 权限与安全
新会话使用高熵随机令牌，只在数据库保存令牌哈希；浏览器 Cookie 使用 HttpOnly、Secure、SameSite=Lax 和七天到期。发布、当前用户、退出接口共用本站会话验证，并确认 users 记录存在。禁用 GitHub 登录入口与回调的会话创建；旧 GitHub Cookie 不获得发布权限。旧作品不删除、不擅自迁移到其他用户。

所有状态变更接口检查同源 Origin，校验输入长度与格式。注册协议版本由服务器定义，前端不能自行声称同意。注册与登录页面提供真实且标明本站主体的协议和隐私说明，披露邮箱用途、邮件处理服务和账号数据。只允许站内返回路径。退出删除服务器会话并清 Cookie。

## 验证与交付
测试验证码过期、错误次数、重发限流、并发消费、重复注册、缺失配置、SMTP 故障、登录/退出、旧 GitHub 会话拒绝和未登录发布 401。类型检查与构建通过后部署，核对运行时秘密保留。用用户指定邮箱测试真实邮件到达并完成注册，确认只有注册后可发布且主页显示新作品；未做实际邮件及注册测试时明确报告未完成。

## 范围
本次不做微信、手机号、密码找回、账号合并或历史作品认领。SMTP_PASSWORD 已通过 CLI 元信息确认存在，但尚未验证 SMTP 认证或邮件投递。
