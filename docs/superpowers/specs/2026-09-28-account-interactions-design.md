# 个人中心互动记录设计

## 目标

让登录用户在创作者中心集中查看自己对产品做过的互动，并从记录重新打开仍可访问的产品。

## 页面与入口

- 在创作者中心增加“我的互动”入口。
- 页面提供“我的喜欢”“我的收藏”“我的转发”“我的举报”四个分类。
- 每条产品记录展示标题、创作者、时间和状态，并在产品仍可访问时提供详情链接。
- 空分类显示简短说明；接口失败时显示错误和重试入口。
- “我的关注”目前尚未实现。本期明确标为“暂未开放”，不提供虚假的关注数据。

## 各类记录

### 喜欢与收藏

- 查询 `creation_likes` 和 `creation_favorites` 中当前用户的记录。
- 按互动时间倒序排列。
- 产品已下架或删除时保留用户记录；仍存在的产品可打开详情，已删除产品显示“产品已不可用”。

### 转发

- 当前 `creation_shares` 只记录产品、分享方式和时间，没有用户 ID，不能把既有转发准确归属给用户。
- 为表增加可空 `user_id` 并兼容现有记录。
- 已登录用户之后成功发起的转发写入自己的 ID；游客分享仍可正常使用，但不计入个人转发记录。
- 既有匿名分享继续保留为匿名统计，不回填到任何账号。

### 举报

- 查询 `site_reports` 中当前用户提交的产品举报。
- 展示举报原因、提交时间、处理状态以及产品当前是否仍可访问。
- 不在个人页面提供修改或撤回举报的操作。

## 数据与安全

- 新增需登录的个人互动读取接口，用户 ID 必须取自服务端会话，不能接受客户端指定其他用户。
- 分享记录仅在完成实际分享动作后写入；写入的用户 ID 来自服务端会话。
- 使用兼容式数据库迁移为分享表增加可空用户字段，不破坏历史记录。
- 产品标题、slug 和创作者名称从关联产品及账号数据读取；产品已删除的举报仍需显示举报记录本身。

## 验收标准

1. 创作者中心有清晰的“我的互动”入口。
2. 喜欢、收藏和举报列表仅返回当前登录用户自己的记录，倒序展示。
3. 登录用户从本期上线后发起的转发会出现在“我的转发”；游客分享不要求登录。
4. 旧分享不被错误归属给任何用户。
5. 产品不可访问时仍能看到历史记录及明确状态，不出现失效链接。
6. “我的关注”明确显示暂未开放。
