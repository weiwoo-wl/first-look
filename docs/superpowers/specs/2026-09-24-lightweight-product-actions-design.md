# First Look 轻量产品行为模块设计

## 目标

为产品增加轻量的用户行为，让用户可以表达兴趣和传播产品，但暂时不建设评论、聊天或用户关系系统。

## 范围

本模块只包含：

- 喜欢
- 收藏
- 分享
- 浏览次数

本模块不包含：

- 评论和回复
- 私信和聊天
- 关注用户
- 用户动态
- 通知中心
- 评分和打分
- 社区等级或积分

## 用户权限

游客可以：

- 查看喜欢数量
- 查看收藏数量
- 查看分享入口
- 查看浏览次数

登录用户可以：

- 喜欢或取消喜欢
- 收藏或取消收藏
- 复制并分享产品链接

所有写入行为都要求登录。未登录用户点击喜欢或收藏时，提示登录，不丢失当前页面。

## 产品卡片

产品卡片保留当前视觉和浏览方式，只增加轻量数据：

- 喜欢数量
- 收藏状态不在卡片上单独展开，避免卡片变得拥挤
- 视频和图片展示不改变

卡片上的分享按钮不直接复制链接，避免用户误触。分享动作放在产品详情页。

## 产品详情页

详情页在产品标题或产品简介附近放置一组操作：

- 喜欢按钮和数量
- 收藏按钮和数量
- 分享按钮
- 浏览次数

喜欢和收藏使用明确的选中状态。操作成功后立即更新数量和按钮状态，失败时恢复原状态并显示可理解的错误提示。

## 数据规则

### 喜欢

- 同一用户对同一产品只能有一条喜欢记录。
- 再次点击取消喜欢。
- 产品喜欢数量由记录汇总，不允许前端自行永久保存结果。
- 现有 `creation_likes` 表和 `/api/creations/react` 点赞基础继续复用。

### 收藏

- 同一用户对同一产品只能收藏一次。
- 再次点击取消收藏。
- 收藏数量与喜欢数量分开统计。
- 收藏记录归属于用户和产品，产品下架后不在公开页面展示。

### 分享

- 分享使用当前产品 URL。
- 点击后复制链接，并显示“链接已复制”。
- 每次成功点击记录一次分享事件。
- 分享不要求用户登录，因为分享本身是传播行为。

### 浏览

- 打开已发布产品详情页时记录一次浏览。
- 同一用户或同一匿名浏览器在短时间内重复刷新不重复计数。
- 防重复窗口由服务端控制，不能只依赖前端。
- 草稿、下架产品和不存在的产品不增加公开浏览量。

## API 边界

每种行为独立处理，避免一个功能失败影响其他功能：

- 互动状态接口：返回当前用户的喜欢、收藏状态及公开数量。
- 喜欢接口：切换喜欢状态。
- 收藏接口：切换收藏状态。
- 分享接口：记录分享事件并返回复制所需的产品 URL。
- 浏览接口：以幂等方式记录一次有效浏览。

接口都必须验证产品仍然是公开发布状态。涉及用户的写入接口必须验证登录身份和请求来源。

## 错误处理

- 未登录操作喜欢或收藏：提示“请先登录”。
- 产品已经下架：提示“这个产品暂时不可用”。
- 数据库暂时不可用：保留原页面内容，提示稍后重试。
- 复制链接失败：显示产品 URL，并允许用户手动复制。
- 重复请求：返回当前最终状态，不重复增加数量。

## 验收标准

- 游客能看到所有公开互动数量。
- 登录用户可以喜欢、取消喜欢、收藏、取消收藏。
- 同一用户重复点击不会产生重复记录。
- 分享可以复制当前产品链接并记录分享事件。
- 产品详情浏览量具备短时间防重复能力。
- 评论、聊天、关注、评分和通知不会被引入。
- 现有登录、发布、产品展示和详情页面不回归。
